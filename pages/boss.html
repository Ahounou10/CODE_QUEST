Bienvenue dans l'arène

Les défis Boss sont des épreuves qui te permettent de vérifier si tu maîtrises les notions d'un niveau.

Pour réussir, tu dois réfléchir, organiser ton code, résoudre les problèmes et tester ton résultat.

Les règles de l'arène

  1. Révise les notions du niveau concerné.
  2. Lis attentivement les objectifs du défi.
  3. Réalise le travail sans copier aveuglément une solution.
  4. Teste ton résultat et corrige tes erreurs.
  5. Explique ce que tu as fait et pourquoi.

Boss 1 — Le gardien du HTML

Mission : construire une page complète

Niveau : Débutant

Technologie : HTML

Objectif

Crée une page de présentation d'un développeur débutant, avec un contenu bien organisé.

Contraintes

  • Utiliser une structure HTML complète.
  • Ajouter un titre principal et des sous-titres.
  • Créer plusieurs sections.
  • Ajouter une liste de compétences.
  • Insérer au moins un lien et une image.
  • Organiser la page avec des éléments sémantiques.

Conditions de réussite

  • Le document HTML est correctement structuré.
  • Les éléments sont utilisés à bon escient.
  • Les liens et l'image possèdent des chemins corrects.
  • Le contenu est compréhensible et organisé.

Récompense prévue : validation du défi et possibilité de passer au niveau suivant.

Réviser la leçon HTML | S'entraîner avant le Boss

Boss 2 — Le maître du design

Mission : transformer une page en interface web

Niveau : Intermédiaire

Technologies : HTML et CSS

Objectif

Transformer une page HTML existante en une interface claire, cohérente et adaptée aux petits écrans.

Compétences attendues

  • Choisir des couleurs et une typographie cohérentes.
  • Organiser les éléments avec Flexbox ou Grid.
  • Gérer les espacements et la hiérarchie visuelle.
  • Adapter l'affichage aux téléphones.

Statut : Défi à réaliser après l'apprentissage du CSS.

Boss 3 — Le stratège JavaScript

Mission : créer une application interactive

Niveau : Avancé

Technologies : HTML, CSS et JavaScript

Objectif

Construire un quiz interactif qui vérifie les réponses, calcule un score et affiche un résultat.

Compétences attendues

  • Utiliser des variables et des conditions.
  • Manipuler les événements.
  • Mettre à jour le contenu d'une page.
  • Organiser et tester le code.

Statut : Défi à réaliser après l'apprentissage de JavaScript.

Boss final — L'architecte d'applications

Mission : construire une application complète

Niveau : Expert

Technologies : HTML, CSS, JavaScript, PHP et MySQL

Objectif

Concevoir une application avec des formulaires, des comptes utilisateurs, une logique côté serveur et une base de données.

Compétences attendues

  • Structurer une application web.
  • Valider et traiter les données reçues.
  • Interagir avec une base de données.
  • Appliquer les bonnes pratiques de sécurité.
  • Tester les fonctionnalités principales.

Statut : objectif final du parcours, à réaliser après les paliers nécessaires.
