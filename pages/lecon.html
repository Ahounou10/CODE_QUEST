Parcours HTML · Leçon 1

Découvrir la structure d'une page HTML

Apprends à construire la base d'une page web avant de lui donner du style.

Objectifs de la leçon

À la fin de cette leçon, tu seras capable de :

  • Expliquer le rôle du HTML.
  • Reconnaître la structure de base d'une page HTML.
  • Identifier le rôle des principales balises.

1. Qu'est-ce que le HTML ?

Le HTML est un langage de balisage qui permet de structurer le contenu d'une page web.

Il permet notamment d'organiser les titres, les paragraphes, les images, les liens et les listes.

2. La structure de base

Voici un exemple minimal de document HTML :

<!DOCTYPE html>
<html lang="fr">
    <head>
        <meta charset="UTF-8">
        <title>Ma première page</title>
    </head>
    <body>
        <h1>Bonjour le monde !</h1>
        <p>Ma première page web.</p>
    </body>
</html>

La partie head contient des informations sur le document. La partie body contient le contenu affiché dans la page.

3. Vérifie ta compréhension

Question 1

Quelle balise contient le contenu principal visible de la page ?

  • <head>
  • <body>
  • <title>

Question 2

Quelle balise représente le titre principal de cette leçon ?

  • <h1>
  • <p>
  • <img>

4. Mission pratique

Crée un fichier HTML contenant un titre principal, deux paragraphes et une liste de trois éléments.

Objectif : reproduire correctement la structure de base.
