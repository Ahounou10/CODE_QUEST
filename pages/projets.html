Construis tes compétences en pratiquant

Dans CODE QUEST, tu ne te contentes pas de lire des cours. Tu appliques ce que tu apprends pour créer des pages web, des interfaces interactives et des applications.

Chaque projet représente une occasion de progresser, de résoudre des problèmes et de gagner en autonomie.

Niveau 1 — Débutant

Projet 1 : Ma première page web

Crée une page web présentant ton nom, tes passions et quelques informations sur toi.

Compétences travaillées

  • Créer une structure HTML.
  • Utiliser les titres et les paragraphes.
  • Organiser le contenu avec des listes.
  • Ajouter des liens et des images.

Technologie : HTML

Projet 3 : Une interface web moderne

Transforme une structure HTML en une interface agréable à consulter, adaptée aux ordinateurs et aux téléphones.

Compétences à développer

  • Mettre en forme les pages avec CSS.

Projet 4 : Un quiz interactif

Crée un quiz qui permet de répondre à des questions, de vérifier les réponses et d'afficher un score.

Compétences à développer

  • Manipuler les événements avec JavaScript.
  • Vérifier les réponses.
  • Calculer et afficher un score.

Technologies : HTML, CSS et JavaScript

Niveau 3 — Avancé

Projet 5 : Une application avec comptes utilisateurs

Développe une application capable d'inscrire des utilisateurs, de gérer leur connexion et de conserver des informations dans une base de données.

Compétences à développer

  • Traiter les formulaires avec PHP.
  • Comprendre les sessions et l'authentification.
  • Enregistrer des données avec MySQL.
  • Appliquer les bases de la sécurité web.

Technologies : PHP et MySQL

Comment réussir un projet ?

  1. Comprendre le problème à résoudre.
  2. Identifier les notions nécessaires.
  3. Préparer la structure du projet.
  4. Écrire le code progressivement.
  5. Tester et corriger les erreurs.
  6. Expliquer ce que tu as appris.
