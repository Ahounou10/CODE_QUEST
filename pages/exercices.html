Les exercices

Entraîne-toi, vérifie ta compréhension et transforme tes connaissances en compétences.

Exercice 1 — Les titres HTML

Objectif : apprendre à organiser les titres d'une page.

Consigne

Imagine que tu crées une page consacrée aux jeux vidéo. Écris un titre principal « Mes jeux préférés », puis un sous-titre « Jeux d'aventure ».

Indice

Le titre principal utilise <h1> et le sous-titre peut utiliser <h2>.

Exemple de correction

<h1>Mes jeux préférés</h1>
<h2>Jeux d'aventure</h2>

Exercice 2 — Les paragraphes

Objectif : utiliser la balise de paragraphe.

Consigne

Écris deux paragraphes : le premier présente CODE QUEST, et le second explique pourquoi tu veux apprendre à coder.

Indice

Chaque paragraphe doit être placé dans une balise <p>.

Exercice 3 — Les liens

Objectif : créer un lien vers une autre page.

Consigne

Crée un lien affichant « Découvrir les cours » qui mène à la page des cours.

Indice

Utilise la balise <a> avec l'attribut href.

Défi final — Ma première mini-page

Crée un fichier HTML contenant :

  • Un titre principal.
  • Un sous-titre.
  • Deux paragraphes.
  • Une liste de trois éléments.
  • Un lien vers une autre page.

Essaie de réaliser le défi sans regarder les corrections. Compare ensuite ton résultat avec les notions de la leçon.
