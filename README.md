# CODE QUEST

CODE QUEST est une plateforme web ludique conçue pour apprendre le développement web en réalisant progressivement des exercices, des projets et des défis.

## Objectif

Apprendre en construisant : chaque étape du projet permet de pratiquer les notions étudiées et de faire évoluer la plateforme.

## Technologies travaillées

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## État du projet

Projet personnel en cours de développement.
